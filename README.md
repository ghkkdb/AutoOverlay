# AutoOverlay

AutoOverlay 是一个 Windows 桌面工具，用于把素材文件夹中的短视频随机覆盖到主视频上，并导出保留主视频原声音的新视频。程序使用 Python/Tkinter 编写，视频处理通过 `imageio-ffmpeg` 调用 FFmpeg 完成。

## 主要功能

- 选择主视频、小视频素材文件夹和导出位置。
- 从素材文件夹中随机选取短视频，按设置的时间片段插入主视频。
- 支持设置小视频截取起始秒、结束秒，并可分别使用固定值或随机区间。
- 支持设置每段素材之间的随机插入间隔。
- 小视频会自动静音，最终视频只保留主视频原声音。
- 小视频会等比例缩放并居中裁剪到主视频分辨率，尽量避免画面变形。
- 默认同一轮处理不重复使用同一个素材。
- 可选择横屏素材文件夹，把横屏素材连续叠加到主视频底部，高度为主视频的 1/3。
- 支持导出前检测素材时长和可用性。
- 支持素材不可用、素材数量不足、素材时长不足时的处理策略配置。
- 支持自动保存上次选择的路径、参数和策略设置。
- 显示导出进度，支持取消导出和打开输出文件夹。
- 点击开始导出前会校验本机授权文件和远程接口状态。

## 项目结构

```text
AutoOverlay
|-- main.py                 # Tkinter 桌面界面入口
|-- overlay_engine.py       # 视频扫描、排程和 FFmpeg 命令生成
|-- licensing.py            # 授权校验和机器码生成
|-- scripts
|   |-- generate_license.py       # 命令行授权文件生成工具
|   |-- license_generator_ui.py   # 授权文件生成界面
|   `-- show_machine_code.py      # 查看当前机器码
|-- requirements.txt        # Python 依赖
|-- build.ps1               # PyInstaller 打包脚本
|-- AutoOverlay.spec        # PyInstaller 配置
`-- README.md
```

## 环境要求

- Windows
- Python 3.11 或更高版本
- PowerShell

程序通过 `imageio-ffmpeg` 使用 Python 依赖携带的 FFmpeg，不要求提前把 `ffmpeg.exe` 安装到系统 `PATH`。

## 本地运行

建议先创建虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```

## 打包

项目默认使用 PyInstaller 打包：

```powershell
.\build.ps1
```

构建完成后运行：

```powershell
.\dist\AutoOverlay\AutoOverlay.exe
```

`dist\AutoOverlay` 是最终可分发的 onedir 文件夹。分发时请保持整个文件夹结构完整，不要删除 `_internal` 目录。

## 使用流程

1. 点击“主视频”，选择需要处理的视频。
2. 点击“素材文件夹”，选择小视频素材所在目录。
3. 如需底部横屏叠加，点击“横屏素材文件夹”选择目录；不需要时留空。
4. 设置“小视频截取片段”，例如起始秒 `5`、结束秒 `8`，表示截取素材第 5 秒到第 8 秒。
5. 设置“随机插入间隔”，例如最小秒 `5`、最大秒 `10`。
6. 选择输出文件路径。
7. 点击“设置”，按需要配置素材异常处理策略和素材检测线程数。
8. 点击“开始导出”。

路径行右侧的“打开”按钮可直接查看已选择的文件或文件夹。软件内也提供“使用说明”按钮，可查看参数解释。

## 参数说明

- 主视频：最终导出的基础视频，导出后保留主视频原声音。
- 素材文件夹：存放小视频素材的目录，支持 `.mp4`, `.mov`, `.mkv`, `.avi`, `.webm`, `.m4v`。
- 横屏素材文件夹：可留空。不为空时，程序会随机选取其中素材，缩放到主视频高度的 1/3 后连续叠加到视频最下方。
- 起始最小秒 / 起始最大秒：每段小视频随机截取起点的范围。
- 结束最小秒 / 结束最大秒：每段小视频随机截取终点的范围，结束最小秒必须大于起始最大秒。
- 最小秒 / 最大秒：两次插入之间的等待时间，最大秒必须大于或等于最小秒。
- 输出文件：导出的 MP4 文件路径，不能和主视频文件相同。

间隔示例：

- `0 - 0`：一个素材接一个素材，中间不等待。
- `1 - 1`：固定间隔 1 秒。
- `2 - 2`：固定间隔 2 秒。
- `5 - 10`：每次随机等待 5 到 10 秒。

## 素材处理规则

- 小视频会全屏覆盖主视频画面。
- 小视频声音不会进入最终输出。
- 小视频分辨率和主视频不一致时，会等比例缩放并居中裁剪到主视频大小。
- 横屏素材视频只会按比例缩放到主视频高度的 1/3，不做截取；如果缩放后宽度超过主视频，会居中显示，超出画面的左右部分不会显示。
- 如果素材无法到达起始秒，可以选择跳过这些素材继续，或停止导出。
- 如果素材数量不足，可以选择重新打乱循环复用、用完后不再插入，或停止导出。
- 如果素材能到达起始秒但不到结束秒，可以选择自动裁到素材可用结尾，或停止导出。
- 素材检测线程数可选择自动或固定线程数；自动模式会按电脑配置取 2 到 8 个线程。

## 授权与接口校验

点击“开始导出”后，软件会先执行授权校验：

1. 读取本机授权文件。
2. 请求接口：`http://www.pandahome023.cn/analysis/api.php?id=188`。
3. 接口返回 HTTP `200` 且内容不包含 `禁止访问` 时，才继续导出。
4. 如果接口无法连接，会每 5 秒重试一次，总等待不超过 1 分钟。

授权文件规则：

- 软件只读取文件名匹配 `license*.lic` 的授权文件。
- 授权文件可放在 `AutoOverlay.exe` 同目录。
- 授权文件也可放在 `%APPDATA%\AutoOverlay`。

机器码由 Windows `MachineGuid` 和主板/整机 UUID 生成，不包含电脑名。用户修改电脑名不会导致机器码变化。

## 生成授权文件

点击软件内“复制机器码”可复制当前设备机器码。

也可以在开发环境运行：

```powershell
python .\scripts\show_machine_code.py
```

命令行生成授权文件：

```powershell
python .\scripts\generate_license.py --machine-code "机器码" --owner "客户名称" --expires-at never
```

也可以打开授权生成器界面：

```powershell
python .\scripts\license_generator_ui.py
```

默认生成的授权文件名格式为：

```text
license_客户名称_机器码.lic
```

例如：

```text
license_张三_02E87796-BDC95C01-D67E99AE-74E80243.lic
```

私钥文件为 `scripts\license_private.pem`，只用于生成授权文件，不会被打包进 `dist\AutoOverlay`。不要把私钥文件提交到公开仓库。

```powershell
python -m compileall .
```

如需验证界面和导出流程，可准备一个主视频、一个短视频素材文件夹和一个输出路径，然后运行：

```powershell

```

## 注意事项

- 分发软件时，请分发整个 `dist\AutoOverlay` 文件夹。
- 不要删除 `_internal` 目录。
- 如果授权校验失败，导出不会开始。
- 如果重新生成了公钥和私钥，旧授权文件会失效，需要重新生成授权文件。
- 本地生成的虚拟环境、构建目录、授权文件和私钥文件不应提交到 GitHub。
